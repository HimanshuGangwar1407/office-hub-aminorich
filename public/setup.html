OfficeHub setup

One-time steps for the administrator. You need the SETUP_KEY you added in Vercel → Settings → Environment Variables.

A. Import your existing data

Choose officehub-data.json (the export of your Claude version: employees, attendance, leave, tasks, approvals, chats, claims, salaries). After importing, every person — you included — opens the main page and uses Create your account with their employee code + work email.

B. Or start empty

Creates the first administrator login. You’ll then set up the company, departments and employees inside the app.

Done? Open OfficeHub
