# OfficeHub — Aminorich Nutrients

Office management in one web app: attendance & punches, CL/SL leave, WFH/OD with live location, tasks,
work-log calendar, approvals (with chosen approver), expense claims & TA/DA, chat (groups, DMs, @mentions,
#tags, pins, reactions), salary sheet & payroll (hour-based, WFH cut, fines, Excel export), access control by
role/department/person, email alerts, and a Ctrl/⌘ K quick search.

## How it is built

| Part | What it is |
|---|---|
| `src/` | The app: plain HTML/CSS/JS split into parts (`part1.html` = styles + shell, `part2…13.js` = features, `part7.js` = routing + boot). |
| `src/vercel-shim.js` | Browser bridge: sign-in screen, local data mirror kept fresh from `/api/sync` (every 5 s), writes, presence. |
| `src/part14-vercel.js` | Small overrides so sign-in/password change use the server. |
| `server/` | API: Postgres storage, scrypt passwords, signed HttpOnly session cookies, access rules, Resend email. |
| `api/main.js` | The one Vercel Function that serves every `/api/*` route. |
| `public/` | What Vercel serves. `index.html` is generated by `npm run rebuild` from `src/`. `setup.html` is the one-time setup page. |

### Security rules enforced on the server
- Everyone must sign in (employee code or work email + password). Accounts are created only for employees HR has added, by matching **employee code + work email**.
- 5 wrong passwords lock the account for 15 minutes. HR/Admin can reset a password (the person then creates their account again).
- **Salary data** (`pay`, `payroll`, `fines`) is only sent to Admins, HR, or people given the *Attendance › Salary sheet* window in Settings → Access.
- Only HR/Admin can add/remove employees or change anyone’s role, code, email or status; only HR/Admin can change Settings; only Admin can change Access.
- Each person’s private data (`data/users/<id>`) is readable only by them. Password hashes never leave the server.

## Deploy on Vercel (first time)

1. **Put this folder on GitHub** – create a *private* repository and upload these files (see *Uploading to GitHub* below).
2. **Import to Vercel** – vercel.com → *Add New… → Project* → pick the repo → Framework preset **Other** → *Deploy*. (No build step runs on Vercel: `public/index.html` is already built. The output folder comes from `vercel.json`.)
3. **Add a database** – in the Vercel project: *Storage → Create → Neon (Postgres)* → connect it to the project. This adds `DATABASE_URL` automatically.
4. **Add environment variables** – *Settings → Environment Variables*:
   - `SESSION_SECRET` – a long random string (32+ characters).
   - `SETUP_KEY` – any 12+ character key you keep private.
   - Optional for real emails: `RESEND_API_KEY` and `MAIL_FROM` (e.g. `OfficeHub <alerts@aminorich.nl>` after verifying the domain in Resend).
   Then *Deployments → ⋯ → Redeploy* so the new variables are used.
5. **Load your data** – open `https://<your-app>.vercel.app/setup.html`, enter the `SETUP_KEY`, choose **officehub-data.json** (sent separately — it is *not* in the repo because it contains salaries), and click *Import*.
6. **Create accounts** – open the app → *Create your account* → employee code + work email + password. Do yours first (AMR001); your record is Admin, so you get every window. Ask each employee to do the same.

The tables are created automatically on the first request.

## Uploading to GitHub (no command line)
GitHub → *New repository* → name `officehub`, **Private** → *Create* → *uploading an existing file* → drag in **everything inside this folder** (including the hidden `.gitignore` — on a Mac press ⌘⇧. to show hidden files) → *Commit changes*.
After that, every change you commit on GitHub redeploys automatically on Vercel.

Or with Git:
```bash
git remote add origin https://github.com/<you>/officehub.git
git push -u origin main
```

## Run on your computer
```bash
npm install
cp .env.example .env          # fill in DATABASE_URL, SESSION_SECRET, SETUP_KEY
node --env-file=.env scripts/build.mjs && node --env-file=.env scripts/dev-server.mjs
# open http://localhost:3000
```

## Changing the app
Edit files in `src/`, then `npm run check` (rebuilds `public/index.html` and syntax-checks it). Commit both `src/` and `public/`.

## Costs & limits to know
- Vercel’s free *Hobby* plan is for non-commercial use; for a company use **Pro** (about $20/month). Each open OfficeHub tab calls the server every 5 s (every 45 s in the background), so ~100 daily users stay well within Pro’s included function usage — change `POLL_MS` in `src/vercel-shim.js` if needed.
- Neon’s free tier (0.5 GB) is plenty for this data; chat files are stored in the database (up to 6 MB each).
- Files shared in chat while the app ran inside Claude are not carried over; messages are.
